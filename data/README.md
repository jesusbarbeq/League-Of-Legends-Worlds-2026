# Datos

Aquí van los CSV de partidas de **Oracle's Elixir** (https://oracleselixir.com, sección *Downloads*), uno por año:

```
2014_LoL_esports_match_data_from_OraclesElixir.csv
...
2026_LoL_esports_match_data_from_OraclesElixir.csv
```

Los CSV **no están incluidos en el repositorio** (pesan mucho y son de su autor). Descárgalos tú y colócalos en esta carpeta, o apunta a otra con la variable de entorno `DATA_DIR`. Revisa las condiciones de uso de Oracle's Elixir antes de redistribuir nada.
